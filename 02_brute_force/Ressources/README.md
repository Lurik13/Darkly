# Comment on obtient le flag?
> Page sign in
> On ajoute "admin" en tant qu'utilisateur
> On teste les 25 mots de passe les plus populaires ici
https://www.superfast-it.com/articles/25-common-passwords
> On peut aussi faire un script et le lancer avec la commande "bash script.sh"
> On obtient le flag avec shadow

# Pourquoi c'est une faille?
Beiiin... Les mots de passe doivent etre safe. Et la il est clairement pas safe. Donc c'est pas bien, surtout pour un admin.

# Comment la resoudre/eviter?
Mettre un meilleur mot de passe pour l'admin, ou juste interdire ces mots de passe communs, mettre des regles exigeant des caracteres speciaux...
